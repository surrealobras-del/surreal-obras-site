# Surreal Construções e Reformas

Site estático responsivo, recriado a partir do mockup fornecido. HTML, CSS e JavaScript, sem dependências de execução.

Execute `npm start` e abra http://127.0.0.1:4173. Os arquivos de publicação ficam em `dist/`.

Inclui menu mobile, comparador antes/depois, filtros de projetos, detalhes dos projetos, carrossel de depoimentos e FAQ. WhatsApp configurado com o número fornecido: (45) 9988-3622; o destino fica em `dist/app.js` e no HTML.

Fotos e textos de depoimentos reproduzem o mockup fornecido. As imagens foram extraídas da referência e têm resolução limitada. Para melhor nitidez, substitua os arquivos em `dist/assets/` pelas fotografias originais. E-mail e depoimentos devem ser revisados pelo responsável antes de divulgação pública. Tipografia: Montserrat em títulos, interface e assinatura, no estilo geométrico do mockup, com fallback para Arial.
